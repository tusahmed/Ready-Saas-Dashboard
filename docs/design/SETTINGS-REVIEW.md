# مراجعة Settings وسلوك القائمة

تمت إضافة الصفحات داخل نظام التصميم الحالي دون إعادة تصميم مستقلة. المرجع البصري هو [تصور البروفايل](horizontal-profile-concept.png)، مع Cairo Bold واللون الكحلي والأسطح البيضاء والحقول والقوائم المستخدمة بالفعل في المشروع.

جرت مراجعة التصور والصور النهائية بأداة `view_image`. صور سطح المكتب ملتقطة عبر Playwright Chromium عند 1536×1024، بنفس مقاس المرجع، لأنه لا توجد أداة Browser/IAB في الجلسة. كما فُحصت الشاشات عند 320 و390 و1100 بكسل في الاتجاهين والوضعين وشكلي التنقل.

| المراجعة | النتيجة |
|---|---|
| الخط | Cairo بأوزان عريضة متناسقة للعناوين والحقول والقوائم. |
| الألوان | امتداد لوحة الألوان نفسها في Light وDark؛ لا تغيير للخلفية أو ألوان التحكم. |
| التوزيع | General يقسم بيانات البيزنس إلى مجموعات، مع اللوجو في عمود جانبي؛ SMTP يقسم بيانات الاتصال والمرسل. |
| المسافات | الحقول والأزرار والبطاقات تستخدم مقاسات النظام الحالي، مع ترتيب اللوجو أولًا على الهاتف. |
| عناصر التحكم | زر اختيار صورة مترجم، معاينة محلية قبل الحفظ، مربعات اختيار وقائمة تشفير وزر إظهار كلمة المرور. |
| التنقل | مجموعة Settings جديدة؛ General حسب الصلاحية، وSMTP للـSuper Admin الفعلي فقط. مجموعة الصفحة الحالية وحدها تبدأ مفتوحة في الـSidebar، والقائمة الأفقية تنتظر التفاعل. |

هذه الصفحات تضيف النصوص المطلوبة لبيانات النشاط والبريد فقط، وترجماتها متاحة باللغات الخمس. البيانات الظاهرة هي بيانات مساحة العمل الفعلية أو حقول فارغة؛ لا توجد حسابات SMTP أو بيانات أعمال افتراضية محفوظة من الاختبارات. يحل اسم البيزنس ولوجوه محل الهوية الافتراضية في اللوحة عند حفظهما، بحسب طلب المستخدم. لا توجد اختلافات بصرية مادية معروفة عن النظام الحالي في الشاشات المفحوصة.

التحقق النهائي: **81 اختبار PHP ناجحًا و674 تحققًا**، و**33 خطوة متصفح ناجحة** تشمل الإعدادات ورفع اللوجو وحذفه وعزل العميل وصلاحيات الإدارة، و**69 فحصًا بصريًا وتفاعليًا** إضافيًا للإعدادات. لا أخطاء JavaScript غير معالجة. [تقرير المتصفح](settings-smoke-report.json)، [تقرير المقاسات والتفاعل](settings-visual-report.json).

اختبارات SMTP بنت ناقل Symfony وفحصت خيارات TLS وSSL والتحول إلى إعدادات البيئة، واختبرت استعادة كلمة المرور بناقل محلي اختباري. لم يتم إرسال رسالة خارجية؛ التحقق مع مزود SMTP الفعلي يحتاج إدخال بيانات المزود وتشغيل الإرسال في بيئة النشر.
