# التحقق والاختبارات

كل الاختبارات الآلية تعمل على **MySQL فقط** داخل قاعدة منفصلة باسم `orbit_saas_test`. ملف `phpunit.xml` يفرض هذا الاتصال، و`tests/TestCase.php` يوقف التشغيل قبل `RefreshDatabase` إذا كان الاتصال أو اسم القاعدة مختلفًا. لا يُستخدم SQLite، ولا تعمل الاختبارات على `orbit_saas`.

## تشغيل PHPUnit

أنشئ قاعدة الاختبار من phpMyAdmin أو MySQL:

```sql
CREATE DATABASE IF NOT EXISTS orbit_saas_test
    CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

الإعداد المحلي في `phpunit.xml`: المضيف `127.0.0.1`، المنفذ `3306`، المستخدم `root`، وكلمة مرور فارغة. غيّر بيانات المستخدم والمضيف عند الحاجة مع الإبقاء على اسم قاعدة الاختبار. قاعدة الاختبار مخصصة للاختبارات ويمكن إعادة إنشاء جداولها تلقائيًا.

من جذر المشروع:

```powershell
php artisan config:clear
php artisan test
```

أو:

```powershell
php vendor/bin/phpunit
```

## ما تتحقق منه المجموعة

- دخول وخروج المستخدم، فشل بيانات الدخول، الحساب المعطل والعميل الموقوف، تقييد المحاولات، وطلب استعادة كلمة المرور واستخدام الرمز ورفض إعادة استخدامه.
- الفصل بين لوحتي المنصة والعميل، ونطاق صفحات المستخدمين والأدوار والبحث ونافذة مستخدمي الدور.
- رفض قراءة أو تعديل أو حذف سجلات عميل آخر، ورفض ربط دور من مساحة عمل أخرى.
- منع ترقية صلاحيات المستخدم عبر حقول مخفية أو منح صلاحية لا يملكها مدير الدور، وحماية حساب المنصة ومالك العميل.
- إنشاء وتعديل وحذف المستخدمين والأدوار والعملاء، وتجزئة كلمات المرور، وإنشاء مالك العميل مع مساحة العمل.
- تعديلات الملف الشخصي وكلمة المرور، وتثبيت اللغات الخمس والثيم وشكل التنقل لكل حساب، ورفض القيم غير المدعومة أو تعديل تفضيلات مستخدم آخر.
- نطاق إشعارات المستخدم، والقراءة والحذف والقراءة الجماعية، والجمهور المستهدف للإرسال، ورفض روابط الإشعارات الخارجية أو التنفيذية.
- إحصائيات Board من البيانات الفعلية، ومعالجة النصوص المدخلة بطريقة لا تعرض HTML تنفيذيًا.
- إلغاء رموز استعادة كلمة المرور القديمة بعد تغيير كلمة المرور، وعزل سجل النشاط لفريق المنصة، ورفض كلمات المرور التي تتجاوز حد بايتات bcrypt أو تتضمن NUL.
- أمر التثبيت لا يستبدل حسابًا قائمًا، ويتحقق من كلمة المرور، وأمر العرض لا يكرر البيانات ولا يعمل في الإنتاج.
- صفحات أخطاء النماذج لا تعيد عرض كلمات المرور داخل مبدل اللغة، وأخطاء إنشاء العميل لا تحتفظ بكلمة مرور المالك في بيانات الجلسة القديمة.
- عزل إعدادات General، والتحقق من اللوجو ونوعه وحجمه، واستبداله وحذفه بعد نجاح المعاملة، والاحتفاظ به عند التراجع، وتنظيفه عند حذف العميل.
- حصر SMTP في Super Admin، وتشفير كلمة المرور وعدم عرضها أو الاحتفاظ بها ضمن المدخلات القديمة، وحفظ المسافات فيها، والحفاظ عليها أو حذفها صراحة.
- تطبيق إعداد SMTP المحفوظ وخيارات TLS/SSL وعدم التشفير، وإعادة ناقل البيئة بعد التعطيل، واستعادة كلمة المرور بناقل بريد اختباري دون شبكة خارجية.
- بدء الـSidebar بمجموعة الصفحة الحالية وحدها مفتوحة، وبقاء القوائم الأفقية مغلقة حتى التفاعل.

## مراجعة المتصفح

اختبار المتصفح الاختياري موجود في `tests/browser/smoke.cjs`. Node وPlaywright مطلوبان لهذا الاختبار على جهاز التطوير فقط؛ لا يتم رفعهما أو تشغيلهما على cPanel. بعد تشغيل التطبيق المحلي وإنشاء بيانات العرض:

```powershell
cd tests/browser
npm install
npx playwright install chromium
npm test
```

الاختبار يسمح بعناوين localhost فقط، وافتراضيه `http://127.0.0.1:8000`. يمكن ضبط `SAAS_URL` عند تغيير المنفذ. ينشئ عميلًا ومالكًا ودورًا ومستخدمًا مؤقتين عبر الواجهة، ويتحقق من الصلاحيات والإشعارات المباشرة واللغات والثيم والموبايل، ثم يحذف البيانات المؤقتة عبر نوافذ التأكيد. ينتج تقرير JSON وصورًا داخل `tests/browser/artifacts`؛ هذه الملفات لا تدخل Git. بيانات العرض الأصلية تبقى موجودة.

شغّل `npm run test:redesign` من المجلد نفسه للتحقق من تفاصيل الواجهة الجديدة: إظهار كلمة المرور، القوائم المنسدلة بالكتابة ولوحة المفاتيح، الحقول المطلوبة والمعطلة، مربعات الصلاحيات، حفظ التنقل الأفقي من البروفايل، قوائم المرور، ومصيدة التركيز داخل قائمة الموبايل. الاختبار لا ينشئ سجلات أعمال، ويستعيد تفضيلات الحسابين بعد انتهائه. ينتج ملفاته المؤقتة في `.tools/redesign-qa`.

استخدم نسخة محلية وبيانات `saas:demo`. راجع صفحات تسجيل الدخول وBoard والعملاء والمستخدمين والأدوار والملف الشخصي والإشعارات على الكمبيوتر والهاتف، في العربية RTL والإنجليزية LTR، ومع الوضعين الفاتح والداكن. اختبر فتح القوائم والـsidebar ونافذة مستخدمي الدور بالماوس ولوحة المفاتيح، وابحث عن مستخدم، ثم غيّر اللغة والثيم وأعد تحميل الصفحة للتأكد من الحفظ.

أرسل إشعارًا من حساب المنصة إلى العميل المفتوح في جلسة متصفح أخرى، وتأكد من ظهوره داخل مركز الإشعارات والتنبيه المنبثق بعد دورة polling. جرّب الحفظ والحذف لتأكيد رسائل النجاح وتأكيد الحذف. استعادة البريد في الاختبارات تستخدم ناقل بريد وهميًا؛ إرسال SMTP الحقيقي يحتاج تحققًا بعد وضع بيانات مزود البريد.

نتيجة الاختبارات المحلية لا تعني أن إعدادات شركة الاستضافة تم اختبارها؛ راجع الدومين وPHP وMySQL وSMTP والكوكيز بعد النشر الفعلي.
